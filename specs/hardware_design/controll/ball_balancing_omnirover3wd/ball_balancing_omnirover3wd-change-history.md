# 玉乗り3WDオムニローバー 仕様変更記録

正本モデル `ball_balancing_omni3_multibody_lqi_rev2.slx` に至る重要な仕様変更のみを記録する。変更前の状況と変更理由を残し、性能の経緯は git 履歴と `matlab_ws/ball_balancing_omni3/README.md` の検証記録を参照する。

## 1. ハードウェア仕様

| 項目 | 変更前 | 変更後 | 理由 |
|---|---|---|---|
| ボール | 直径150 mm・300 g | 直径100 mm・285 g 薄肉リジッド球（ゴムスプレー被覆想定） | 製作ボールの設計基準変更。球慣性は薄肉球式 $(2/3)mR^2=4.75\times10^{-4}I_3$ を維持 |
| オムニホイール | Nexus Robot 14108（φ48・幅25.1 mm・8ローラー・約39 g） | goBILDA 48 mmオムニホイール（幅18 mm・12ローラー・32 g・50Aローラー） | 実機選定の確定。質量・ローラー層剛性をモデルへ反映 |
| 車輪接触緯度 $\lambda$ | 45°（初期）→55°（100 mm球適合時）→65°（同軸外向きモーターポッド案）→40° | 33° | 40°化: 輪法線力 $N=mg/(3\sin\lambda)$ が緯度低下で増大しトラクション限界トルクを引上げ（減速コーナー脱輪の根本原因解消）。33°化: 案B内向きモーター格納の幾何学的成立限界（外向きポッドは尾部が地面接触）。CG+20 mm上昇を法線力+18%・傾斜慣性-42%が相殺し性能同等以上を確認 |
| モーターポッド質量モデル | 内向き格納の推定値（`motorComAboveBall`等） | Fusion 360 実測 MotorMount_v12 部品表 | 案B CAD確定後の実測置換（テスト参照値更新・19/19合格） |
| 駆動系 | 理想速度源/トルク源 | FIT0521（6 V・210 rpm・$K_t$=0.3065 N·m/A・$R_a$=1.875 Ω・減速比34.02）＋MDD3A×2（ブリッジ抵抗0.35 Ω・PWM 20 kHz）のSimscape Electrical回路、PWM duty入力 | 実機rev1ハード構成の再現。電気時定数・ブリッジ損失・デューティ制限をプラントに反映 |
| 電源 | 未規定 | Zeee 7.2 V 5000 mAh NiMH（0.423 kg・内部抵抗0.09 Ω・充電8.4 V/カットオフ6 V）、duty上限 6/7.2≈0.833（FIT0521定格6 V平均） | 実機電装構成の確定 |
| IMU | 理想センサー | LSM6DSO相当（ジャイロ 3.8 mdps/√Hz・±2000 dps量子化、加速度 75 µg/√Hz・±4 g量子化、バイアス・シード固定ノイズ注入） | 実機IMU選定（NUCLEO-STM32G474RE 実装想定）。EKFプロセスノイズと同一シート値を共用 |
| エンコーダー | 連続値 | FIT0521内蔵2相Hall、出力軸341.2 PPR量子化（0.0184 rad）。逓倍はx1保留（実機受入試験で確定） | 量子化フリッカーが制御帯域の支配的ノイズ源であることが判明したため |

## 2. プラント仕様

| 項目 | 変更前 | 変更後 | 理由 |
|---|---|---|---|
| 輪–球接触剛性 | $k_n$=2–3$\times10^{5}$ N/m級の単一値 | ボール膜 $3\times10^{4}$ N/m とローラー層 $2.5\times10^{4}$ N/m の直列合成 $1.36\times10^{4}$ N/m（減衰170は臨界整合） | オムニホイール素材（50Aゴムローラー層）の実物反映。高剛性側で10°保持 ~13 s の崖があるため剛性掃引を受入マトリクス化 |
| 球–床接触剛性 | $1\times10^{4}$ N/m | $3\times10^{4}$ N/m・減衰500 | プラ球＋ゴム膜の実物推定値 |
| 球–床摩擦 | $\mu_s=\mu_d$=2.0 | 1.2 | 実機想定 ~0.8 への保守側上乗せ（未定義の実床に対し余裕を持つ） |
| 球–床転がり抵抗 | なし | 係数 0.008（許容帯0.005–0.015）＋スピンスクラブ項 | フローリング〜短毛絨毯の実抵抗。速度平衡と惰行包絡の評価に必須 |
| 輪–球摩擦 | 駆動方向 $\mu_d$=0.75・ローラー方向 0.02 | 駆動方向 $\mu_s=\mu_d$=2.0・ローラー方向 0.02 | ゴム被覆球×ゴムローラーの実グリップ想定。トラクション推定は別途 $\mu_{est}$=1.0 で保守運用 |
| 輪軸摩擦 | 粘性のみ | Coulomb 0.0199 N・m＋breakaway 0.0239 N・m（augment追加） | FIT0521ギヤード出力軸の実静摩擦 |
| 駆動系デッドゾーン | なし | duty域不感帯をプラントへ印加（`drive.deadzonePlantPos/Neg`、輪別・方向別の掃引同定値） | 実駆動系の固着帯。FR-16補償と対で管理 |
| 電源電圧依存 | 固定6 V相当 | `driver.supplyVoltage`=7.2 V・`maxDutyCycle`=0.8333・ブリッジ抵抗込みの duty 反転 | 実電源定格とモータ定格の整合 |

## 3. 制御仕様

| 項目 | 変更前 | 変更後 | 理由 |
|---|---|---|---|
| 制御出力 | 輪速指令（10状態LQI＋輪速PI→電圧）または階層制御トルク配分 | トルク入力LQI（姿勢トルク）＋推進輪速サーボ＋DCモータ式 duty 反転 `duty=((R_a+R_{br})I+K_e\omega)/V_s` | 輪速サーボ外周では傾斜フィードバックがモータ電気時定数より遅く、接触過渡に追随できなかった。トルク直接出力で電気時定数まで短縮 |
| 実行レート | 単一 5 ms | 外側200 Hz（姿勢・推定・モード）＋内側1 kHz（推進サーボ・duty反転）のマルチレート | NUCLEO-STM32G474REへの「Treat each discrete rate as separate task」マルチタスク実装を見据えた分離。輪速計測は量子化フリッカー（1 ms差分で±18.5 rad/s/カウント）回避のため5 ms窓を維持 |
| LQIゲイン | 公称質量点の線形化LQR | `ballbotRobustTorqueGains` のロバスト固定ゲイン（実測B行列をペイロード族0–1 kgへスケーリング、最悪閉ループ極半径最小の重端設計＋経験列スケーリング tilt×1.8・yaw-rate×5、R=4000） | 単一固定ゲインでペイロード族全体の保持床を満たす必要がある。実測B行列採用は線形化モデル誤差の排除 |
| 速度積分 | 条件付き積分（アンチワインドアップ付き）を出力へ接続 | 休眠経路（簿記のみ、`integralGain`=0）。定常抵抗は無状態ドラッグFF（`dragLeanFeedforward`×$r_f g$、片側適用） | 輪トルク経路の積分は内力でボールを動かせず、リーン経路の積分は蓄積バイアスで ~0.9 m/s 暴走を反復した。無状態FFは風袋バイアスを持たない |
| 指令トルク上限 | トラクション推定で指令をクリップ（`commandTorqueLimit`） | `commandTorqueLimit`=`continuousTorqueLimit`（指令はクリップせず、合成トルクのみトラクション上限0.162 N・mで制限） | 指令クリップが姿勢回復需要まで縮退させていたため |
| トラクション上限 | 0.078 N・m（65°時代の静止荷重4.07 Nに依存） | 0.162 N・m（λ33実測静止荷重8.45 N/輪、$\mu_{est}$=1.0・80%ディレート） | 旧値は推定側の飢餓で実際の接触予算の半分だった。修正で10°ロール ~39 s 保持・転倒なし |
| リカバリ権限 | `recoveryWheelTorqueLimit`=2×公称 | =公称値（0.162 N・m） | 2倍権限は10°起立で過権限スリップを起こし ~0.6 s転倒 |
| mode 0 | fallen→recovery復帰経路あり | 終端状態（復帰なし）＋進入時シミュレーション打切り | 床バウンスで35°を割るたびに再突入し反復フェースプラントを起こした。実機破損防止の安全仕様 |
| RECOVERY閾値 | 進入17°・退出なし | 進入5°・退出2°（ヒステリシス） | 初期傾きが大きい起立時の早期発動。退出即値だとドリフト再傾斜でmode 1を往復したためヒステリシス化 |
| 推定器姿勢補正 | 静止ゲート付き比例補正（$K_a$=2.5、$\|\|f\|-g\|\le0.25g$） | 誤差状態EKF（$\delta\theta$3＋$\delta b_{g,xy}$2、共分散伝播・Joseph形・傾き分散フロア）＋運動モデル3証人による更新可否判定 | 比例補正は動作中に幻影傾斜（推定±1.8 rad）を生じた。残差注入型の全変種は寄生相殺/自己参照で悪化し、有効性ゲートのみが実測で安定。静止保持0.011→0.0023 rad（1/5） |
| 輪速計測 | 制御周期と同一 | 計測窓5 ms固定（内側1 kHzでも5 ms計測値を使用） | 1 ms後退差分は量子化±18.5 rad/sのフリッカーをdutyへ注入して保持を破壊した |
| 輪速オブザーバ | `wheelRateObserverEnabled`=true（driveGain=306） | false（既定） | driveGain が荷重応答を ~100倍過大予測し推進を抑制（λ33速度頭打ちの第1原因） |
| デッドゾーン補償 | なし | FR-16補償（`drive.deadzoneCompPos/Neg`、duty符号別・輪別同定値、内側タスクで加算。ファーム`wheel_servo.cpp`同等） | 駆動系固着帯の補償。オンライン適応PoCは反転時にcompがラチェットして名目的動作でも転倒したため未接続 |
| 指令速度上限 | 滑り限界理論値 ~0.71 m/s相当 | `maxSpeed`=0.40 m/s | 実測包絡: ≥0.5 m/sは低摩擦で転倒、≥0.6 m/sは全摩擦で転倒（ボール追い越しを戻すブレーキが物理的に存在しない） |
| ヨー指令包絡 | 持続ヨー回転を許容 | 総回転 ~0.4 rad/回以下のバースト限定。cycle既定は隔周期0.1 radバースト（`cycleYawEvery`=2）、採点cycleはヨー無しにピン留め | コモンモードトルクがボール自由zスピンをポンプして脱輪。毎周期ヨー窓は0.1 radでも蓄積転倒 |
| リーン外側ループ | 速度PI→傾斜指令 | 速度誤差→リーン整定点（P＋加速度FF＋ドラッグFF）＋リーン上限0.022 rad・スルー制限・コーンフェード・偏心ガード・コーストゲート（全てブレーキ成分を殺さない片側適用） | 減速コーナー脱輪・移動脚突入の偏心キック・追い越しボールのフェースプラントの実測失敗形態への構造対策 |
| settle制御 | なし | elevatedAuthority 中はエンコーダー運動学レートへ速度証人を切替＋settle専用フォロー/リーン/減衰ゲイン | 推定器のボール/機体速度はドリフト中に ~7倍/~3倍バイアスがあり、そのブレーキが再傾斜をポンプした |
| 静的リーン適応 | なし | `staticLeanAdapt`（指令0時のドリフト速度をリーン整定点バイアスへ学習） | CGオフセットで平衡リーンが必要な場合、tilt=0保持がオフセット方向へドリフトし脱輪していた |
