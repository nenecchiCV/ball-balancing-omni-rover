## 1. 目的

3輪オムニ機構を球の駆動系として用い、固定結合を持たないローバーを球上に維持しながら、ワールド座標の任意方向並進速度とヨー角速度を追従させる。制御器は理想6軸IMUと3輪エンコーダーのみを入力とし、ボール回転、機体速度、機体–ボール相対変位を内部推定する。

## 2. 成功条件

| ID | 指標 | 目標 | 検証 |
|---|---|---:|---|
| G-01 | 静止時ロール・ピッチ | 定常値 ±1 deg | 閉ループMIL |
| G-02 | 0.10 m/s速度ステップ | 整定誤差 ±0.01 m/s | 閉ループMIL |
| G-03 | 0.5 rad/sヨー速度ステップ | 整定誤差 ±0.05 rad/s | 閉ループMIL |
| G-04 | 接触維持 | 3輪接触率 99%以上 | truthログのみで判定 |
| G-05 | ボール–床接触維持 | 分離時間 0 s | truthログのみで判定 |
| G-06 | 推定姿勢 | ロール・ピッチ誤差 0.5 deg以内 | truthとの比較 |
| G-07 | 推定速度 | 平面速度誤差 0.02 m/s以内 | truthとの比較 |
| G-08 | アクチュエーター制約 | 輪速・輪トルク上限超過なし | 回転変位ログの差分値とトルクログで判定 |

## 3. 適用範囲

| 対象 | v1 |
|---|---|
| 物理モデル | 剛体、球–床接触、3組のホイール–球接触、接触分離、異方性摩擦 |
| 制御 | 平面速度、ロール・ピッチ、ヨー角速度、モード、飽和、積分器アンチワインドアップ |
| 推定 | 姿勢、平面速度、ボール角速度、機体–ボール相対変位、接触信頼度 |
| センサー | 理想比力、理想角速度、理想車輪回転変位 |

| 非対象 | 理由 |
|---|---|
| 実機IMUバイアス・ノイズ・温度依存 | 理想センサー段階を先に閉じるため |
| ボール変形の有限要素モデル | 接触ペナルティモデルで制御帯域を評価するため |
| ローラー個別剛体 | 異方性摩擦として等価化するため |
| 絶対位置の長期保持 | IMU・エンコーダーのみでは絶対位置が観測不能なため |

## 4. 運転シナリオ

| ID | 条件 | 指令 | 期待動作 |
|---|---|---|---|
| S-01 | 直立・静止初期値 | $v_d=0$, $r_d=0$ | ロール・ピッチ0、全接触維持 |
| S-02 | 直立 | $v_{x,W}:0\rightarrow0.10$ m/s | 一時的前傾後、速度追従 |
| S-03 | 直立 | $v_{y,W}:0\rightarrow0.08$ m/s | 一時的横傾斜後、速度追従 |
| S-04 | 直立 | $r_d:0\rightarrow0.5$ rad/s | 並進速度を維持してヨー回転 |
| S-05 | 10 deg初期傾斜 | $v_d=0$, $r_d=0$ | BALANCEで直立復帰 |
| S-06 | 20–35 deg傾斜 | 任意 | RECOVERYで速度・ヨー指令を抑制 |
| S-07 | 35 deg以上 | 任意 | FALLENでトルク0、積分器リセット |
| S-08 | 摩擦係数-20% | S-02 | 飽和下で接触維持、性能劣化を記録 |

## 6. 運転モード

| 値 | モード | 進入条件 | 動作 | 積分器 |
|---:|---|---|---|---|
| 0 | DISABLED/FALLEN | `enable=0` または傾斜≥35 deg | 全輪トルク0 | 0へリセット |
| 1 | BALANCE | 傾斜<18 deg、接触信頼度≥0.20 | 速度・姿勢・ヨーの全制御 | 条件付き積分 |
| 2 | RECOVERY | 傾斜18–35 degまたは接触信頼度<0.20 | 速度・ヨー指令0、姿勢ゲイン1.35倍 | 0へリセット |

## 8. 観測可能性の境界

| 状態 | 理想条件での扱い | 実機で必要な追加情報 |
|---|---|---|
| ロール・ピッチ | 加速度方向+ジャイロで推定 | バイアス同定 |
| ヨー | 初期値+ジャイロ積分 | 磁気・視覚・外部方位 |
| 平面速度 | 比力積分+接触運動学で推定 | 外部速度または位置補正 |
| 絶対平面位置 | 制御対象外 | GNSS、UWB、LiDAR、視覚 |
| ボール角速度 | 車輪回転変位の微分値+地面無すべり仮定で推定 | ボールマーカー等 |
| 接触分離 | 運動学残差から信頼度を推定 | 荷重・距離センサー |
