# 車輪接触緯度 33°・案B（内向きモーター格納）CAD変更計画書

対象: Fusion 360 プロジェクト `nenecchi/ball-balancing-omni-rover` 内 `ball_balancing_omnirover3wd_assembly`
シミュレーション側は λ=33°・内向きポッド質量モデルを既定化済み（既定値で cycle 完走 0.35°・7/9、hold 0.15°・7/7、yaw 完走、CG-20mm 1.62°保持）。本計画はCADを同一幾何へ整合させる。

## 1. 設計決定の経緯

- 外向きポッド案は最大外形 Ø~245–250 mm に拡大するため不採用（MotorMount_v10 はλ65復帰原因の除去のため削除済み）
- 内向き格納（案B）は幾何学的に **λ ≲ 33° でのみ成立**（3本の ~67 mm モーターが中心軸へ収束し、尾部同士の隙間が尽きるため）
- λ=33° の制御影響を評価した結果、λ=40° と同等以上（法線力 +18%、hold/yaw 改善、CG +20 mm 上昇をトラクション余裕が相殺）→ **λ=33°・案Bを採用**

## 4. 案Bの主要な設計課題（定量化済み）

| 課題 | 値 | 対策 |
|---|---|---|
| 尾部相互隙間 | 隣接尾部間隔 **25.4 mm** vs 尾部外径 ~Ø24.4 → **実効隙間 ~1 mm** | フェースギャップ $s$ を 20.6→18 mm へ最小化（+1.7 mm 改善）。公差を考えれば限界設計 — エンコーダキャップ形状の実測確認が前提 |
| L1 との干渉 | 尾部 z = 163.3 mm が L1（147–150 mm）を ~13 mm 貫通 | **L1 中央に貫通開口を新設**（3尾部はデッキ面を半径 ~15–25 mm 域で通過 → 中央の単一開口 Ø~70–90 または3スロットで全尾部を逃がす） |
| バッテリー配置 | L1 中央搭載の NiMH パック（140×50×25）が開口・尾部と干渉 | L2 への移設、または L1 上の偏心配置へ変更（質量モデル反映必須） |
| 上部ロッド取付 | 中央開口がロッド基部（Ø20 中央穴利用）と干渉の可能性 | ロッド取付位置のずらし or 開口形状の調整 |
| マウント形式 | 外向きポッド用の旧設計は再利用不可 | **MotorMount_v23 新設計**: 締結プレートと同寸外形（48 mm角）の厚壁四角筒＋フェイス板＋フレーム側壁の延長→一様長方形締結プレート（x=34–72.5・y=±34）構成（尾部開口からモーター挿入、筒壁がそのままFrame_L1へ届く、剛性に寄与しない領域は垂直カット、モーター端部下端角の接線平行面取り＋フレーム側楔充填で印刷伏せ対応）。ギアボックス前面M2.5タップへのボルト締結＋角筒の胴体拘束でモーターを保持 |
| 地上クリアランス | ポッド全てが機体内部に収まるため外形・地上高とも改善 | — |
| ボール–モーター隙間 | ~11.8 mm（車軸線は球心から74 mm接線距離を維持） | — |
| 最大外形 | モーター先端の外張りが消え **Ø ~160–170 mm** に縮小（M-09 更新） | — |

## 5. 3Dプリント設計ルール（v22 長方形プレート締結角筒マウントへの適用）

現行 MotorMount 系と同じ造形思想を維持し、複雑な面を持たない解析形状のみで構成する。

- **形状要素**: 平面・円柱の組合せのみ（自由曲面・スプライン面は使用しない）。単一ソリッドの一体成型（角筒＋フェイス板＋フレーム延長壁＋水平フランジ＋延長タブ＋楔充填）
- **オーバーハング**: **締結プレート上面（z=147、Frame_L1 接触面）をベッド面とする伏せ姿勢**が基本。ホイール側下端角を方形に復元し、フレーム側の斜め隙間（+n′壁外面とプレート下面の間）を楔充填したため、伏せ時に筒端がベッドへ面一で届く。筒開口は横向き — サポート要否はスライサー確認
- **締結・ねじ穴**:
  - ギアボックス締結: フェイス板 Ø2.9 貫通穴 ×4（PCD17、M2.5）+ ホイール側ボス Ø6.0 ワッシャーポケット → モーター前面タップへボルト＋Ø5.5ワッシャー。内面 Ø18.4 カウンターボアがモーター前ボスの座面
  - プレート↔L1 締結: 一様長方形締結プレート（z=141–147、x=34–72.5・y=±34）の Ø3.5 垂直穴×4（(44.5,±29)+(62,±29) mm）と L1 板の同位置 Ø3.5 穴を M3 ボルト＋Ø6ワッシャ＋ナットで挟み締結
  - スペーサー締結: Frame_L1/L2/L3 のスペーサー穴 Ø3.5×6/層は回転パターン {0,±60,±120,180}・r=65（旧 {±30,±90,±150} から +30° 回転）。Spacer_M3x50（OD6.2・ボアØ3.2・50 mm）×12 を M3 ボルト＋Ø6ワッシャで締結
  - 中央 Ø8 ノーズ逃げ穴
- **既存穴径の踏襲**: ボア類は印刷後のリーマ・ドリル仕上げを前提

## 6. Fusion MCP 作業手順

全オカレンスが接地固定・非リンク構成のため、コンポーネント変換行列の直接編集で再配置する。

1. **構築ジオメトリ作成**: λ=33° の車軸線・ホイール中心点 (62.1, 0, 90.3) 等を数値定義
2. **ステーション1（方位0°）を先行配置**:
   - `OmniWheel_14108_P0:1` → (62.1, 0, 90.3)、軸傾斜 57°
   - `WheelAdapter_v4:1` → 車軸上でホイール内側へ追随
   - `FIT0521` → **内向きへ反転**（フェース $s=+20.6$ mm、出力軸はホイール側）
3. **MotorMount_v23 設計**: 締結プレートと同寸外形（y±24・n′±24＝48 mm角）の厚壁四角筒（側壁/床壁9 mm・フレーム側壁7 mm、内空30×32、s'=14–58）＋車軸側端のフェイス板（s'=14–18.45）＋フレーム側（+n′）壁を s'=64 まで延長して L1 下面（z=147）へ届かせ、水平締結プレートを一様長方形（x=34–72.5・y=±34・z=141–147）へ拡張して接続する（v20 の主部+翼タブ段差を解消）。締結穴はプレート上の垂直 Ø4.5 (44.5,±29)+(62,±29)×4（旧 (62,±19.5) は充填）。プレート内端（x=34）・外端（x=72.5）より先の材料は垂直カット、+n′壁外面とプレート下面の間の斜め隙間を楔充填し、モーター端部下端角 (34,±24,88.78) はボール・ホイール接線に平行な面（法線=車軸方向、フェイス板と平行）で面取り（締結プレート面をベッド伏せ印刷面とする意図）。プレート内端はU字スロットで尾部コネクタ逃がし。ギアボックス締結は板の PCD17 Ø3.5 貫通穴×4＋ホイール側 Ø7.2 ワッシャーポケット、中央 Ø8 ノーズ逃げ穴、内面 Ø18.4 カウンターボア（モーター前ボス座面）。不要な凹凸・フィレットなし
4. **Frame_L1 更新**: 尾部逃げ穴 Ø48×3（実装済み）＋締結穴を延長タブ位置 (44.5,±29)+(62,±29)×3ステーションへ増設・移設（旧 (62,±19.5) は充填）。**バッテリー・上部ロッドの配置確認を併せて実施**
5. **ステーション2/3 へ複製**: 方位 120°/240° へ原点回り回転で複写
6. **検証・エクスポート** → §7 の受入条件を実施し `cad/` へ STEP/STL エクスポート

## 8. シミュレーション側の対応（既定化済み）

- `ballbotParameters.m`: `contactLatitude = 33°`、内向きポッド質量モデルは **Fusion実測値へ置換済み**（`motorComAboveBall=0.0790`、`motorYawArm=0.0371`、マウント v23=51.44 cm³ CG 78.3/55.6 mm・慣性 ABS換算 mountTiltI=1.58e-5/mountYawI=2.36e-5、アダプタ1.217 cm³、L1板 43.99 cm³、スペーサ M3x50=1107.4 mm³×12）。評価確認は再実行が必要
- バッテリー移設・L1開口が確定したら `chassisParts` の質量/高さ行を更新
- 実測値反映後に hold/stepX/yaw/cycle/CG-20mm を再実行し今回値（hold 0.15°・cycle 0.35°）と回帰比較

## 9. 残課題・オプション

- **尾部隙間 ~1 mm は本設計の最大リスク**: 実測でエンコーダキャップが Ø24.4 を超える場合、または組立公差で接触する場合は λ=30–32° への微調整かフェースギャップ最小化で対処
- **バッテリー・上部ロッドの再配置は未設計**: L1 中央開口の形状と同時に決める必要あり
- **外向き案の代替部品は廃止**: MotorMount_v10 はλ65復帰原因の除去のため削除済み（git履歴に残存）。λ33 内向きが物理的に破綻した場合は本設計を見直す
