# FIT0521モーター固定パーツ設計レポート(v23 長方形プレート締結角筒式・印刷伏せ姿勢)

## 概要

DFRobot FIT0521(φ24.4 × 52 mm、4 mm Dシャフト)を Nexus Robot 14108 オムニホイール(φ48 × 25.1 mm)に同軸直結する配置と、そのモーター固定パーツを設計した。ホイール接触緯度は **λ = 33°**(車軸水平角 57°)、ユーザー指示により **案B(内向き格納)** を採用する。ホイール方位 β = {0°, 120°, 240°} は変更しない。

v9 では **実機で成立するギアボックス締結**を実現するため v12 のモーター締結部を再構成した。v8 の中央 Ø26 挿通ボアは PCD17 タップ半径(8.5 mm)がボア内側に入るためボルト座面となる材料が存在しなかった。v9 ではモーター面を板裏面(現行 s′=20.0 mm 面一)に着座させ、中央ボアを充填し、PCD17 の Ø3.5 貫通穴×4とホイール側ワッシャーポケット Ø7.2×2 mm×4を実体に切削した。

λ = 33° の選定根拠: 案B(モーターを車軸の内向き・上向きに延ばす同軸直結)は3モーター尾部が中心軸へ収束するため λ ≲ 33° でのみ幾何学的に成立する(計画書 §3 の定量化)。λ = 33° は境界値である。

v8→v9 での変更点(実締結構造の実現):

- **モーター締結部を実体ウェブ化**: 中央 Ø26 ボアを廃止し、ギアボックス前面タップ(PCD17、Ø2.5×4)に同軸の Ø3.5 貫通穴×4が板実体を通る構造へ変更
- **ワッシャーポケット**: ホイール側に Ø7.2×2 mm 窪み×4を新設(M3 ボルト頭+ワッシャーを収容、頭頂 s′≈14.5 mm)
- **ノーズ逃げ穴 Ø8**: ギアボックス前面中央の突起逃げ
- **モーター位置**: フェース s′=16.0 → 20.0 mm(板裏面に面一着座)
- **アダプタ再作成**: WheelAdapter_v4 を λ33 同軸の Ø11.9/Ø4.2 貫通チューブとして作り直し(旧姿勢の残存を解消)
- 体積 12.33 → 21.71 cm³(タブ追加・旧穴充填後)

v9→v10での変更点(フレーム締結とフィレット撤廃):

- **フレーム締結をタブ式に変更**: パッド上面を z=141–147 mm のキャップブロックで埋めて幅方向(±y)に張り出すタブとし(y = ±24 mm)、タブに Ø4.5 垂直穴×2((62,±19.5) mm)を切削。Frame_L1 側にも同一XY位置に Ø4.5 垂直穴を開け(3ステーション計6ヶ所)、フレーム板とタブをはさんで M4 ボルト+ナットで締結する方式へ変更
- **旧締結穴の撤廃**: パッド部の Ø4.6 垂直すきま穴×4は新タブ構造に置き換え(現行ボディに Ø4.6 垂直穴は存在しない)
- **フィレット撤廃・面取り化**: 凹角フィレット(R4×3・R2.5×1)を削除し、三角プリズムの結合/切削でフラットな面取り角に置き換え。プロファイルの段差ジグザグも直線化
- **モーター180°回転**: コネクタ干渉回避のため全3モーターを車軸まわりに180°回転
- 天面を z=147 mm で平坦化(Frame_L1 下面と面一密着、干渉0)

v10→v11での変更点(モーター姿勢の恒常化とシャフト係合):

- **モーターをステーション別コンポーネント化**: オカレンス変換(`transform2`)が保存時に旧姿勢へ巻き戻る問題が残存したため、最終姿勢をコンポーネント幾へ直接焼き込んだ FIT0521_P0/P1/P2(恒等変換)へ再構築。保存・再オープンで姿勢維持を検証
- **モーター面を板裏面へ面一着座**: s′=20.6(0.6 mm 浮き)→ s′=20.0 mm(タップ開口位置で実測確認)
- **アダプタ延長でシャフト係合を確保**: WheelAdapter_v4 のモーター側端を s′=+1.5 → +11.5 mm へ延長し、シャフト先端 s′=7.8 との 3.7 mm 係合を実現(ボア Ø4.2、外径 Ø11.9 は不変)
- 全ペア干渉 0 mm³、PCD17 穴整合・3ステーション対称性を再検証済み

v11→v13での変更点(スリーブ式マウントへの全面再設計、v15 で廃止):

- **モーターを筒状部に挿入**: 車軸同軸の回転体カップ(外径 Ø31・ボア Ø25.5、肉厚 2.75 mm)を生成。モーターは内側端(ギヤボックス側 s′≈50 の開口)から挿入され、ボアがギヤボックス前方 s′≈18.5–50 mm の周囲を包む。ボア内端 s′=18.3 がモーター前面(s′=18.5–18.7)の座面となる
- **モーターフェイスと筒壁のねじ止め**: カップ外端(ホイール側 s′=14 のキャップ壁 4.6 mm)に PCD17 同軸 Ø3.5 貫通穴×4 + Ø7.2×3.5 ワッシャーポケット×4 + 中央 Ø8 ノーズ逃げ穴を切削。キャップ内面にはギヤボックス前ボス(Ø17.6×s′≈18.5–21.5 突入)の逃げとして Ø18.4 カウンターボア(s′=15–18.4)を設置
- **面数削減**: キャップ+ウェブ+タブを単一ソリッドへ一体化(旧横穴はプラグ充填、不要な凹凸なし、面取りのみ)。現行ボディ 1 個・面数 39(解析面のみ)
- 体積 21.71 → **18.63 cm³**、CG z=128.1 mm(球心上 78.1 mm)・半径方向 52.7 mm、CG基準主慣性(鋼)≈0.500/0.440/0.185 kg·cm²

## λ65復帰の原因究明と根絶

保存・再計算時にモーターオカレンスがλ65姿勢へ巻き戻る現象が繰り返し発生していた。原因究明の結果、以下を除去した。

- **破損した剛性asBuiltJoint(剛性108)**: 削除済みオカレンスを参照するジョイント(`occPath1.valid()` = InternalValidationError)が、λ65時代に捕捉した変換を再計算時に生存オカレンスへ再適用していた → 削除。削除後の保存でモーター3台のλ33姿勢が維持されることを確認
- **λ65時代の部品エクスポート**: `parts/` の MotorMount_v4/v5/v6/v7/v9、MotorClampStrap_v1、WheelAdapter_v3、`cad/` の fit0521_motor_clamp_strap、fit0521_motor_mount_bracket、MotorMount_v10(外向き)を削除 — 再インポートによるλ65幾何の混入経路を遮断(git履歴には残存)
- **λ65変換で生成された旧モーターオカレンス(:8/:11/:12/:14/:15)**: 削除
- **オカレンス変換の保存時巻き戻し(第2の原因)**: 破損ジョイント除去後も、API で設定した `transform2` が保存時に旧姿勢へ戻る現象が残存した。根絶策として、各ステーションの最終姿勢をコンポーネント幾何へ直接焼き込んだ **FIT0521_P0/P1/P2**(オカレンス変換=恒等行列、巻き戻る変換が存在しない)へモーターを再構築。保存 + 閉じる/再オープン後も λ33 姿勢(ギア面 s′=20.0)が維持されることを検証済み
- **omnirover3wd_reference**: オムニホイール以外は本機と無関係のためディレクトリ削除(READMEのデータシートリンクは `cad/parts/omniwheel_14108.step` 参照へ修正)

残存: Fusionクラウドのドキュメント・バージョン履歴にはλ65版(v1–v17)が残るが、現行ドキュメント内の再計算パスは除去済み。

- **尾部配線**: モーター尾部は Frame_L1 の Ø48 穴を貫通する。エンコーダ配線も同穴経由で引き回す前提(穴径は配線コネクタ通過を含めて確定)
- **Frame_L1 剛性**: Ø48 穴×3が中央開口と繋がり、外周部が残る形状。L1荷重(バッテリ等)に対する剛性確認は残課題
- **アダプタボアの公差**: ボア Ø4.2 とシャフト Ø4.2 は公称ゼロクリアランス。印刷の実寸収縮を考慮し、必要ならボアを Ø4.3–4.5 へ拡大するか挿入後リーマ仕上げとする
- **印刷品質の実機確認**: スライサーでのプレビュー(サポート不要の確認)、実寸公差(Ø8/Ø3.5/Ø7.2/Ø4.6 の実測)、積層方向強度は実印刷で確認する。実装前に公差クーポンの試刷を推奨
