# オムニローバー3WD 駆動部品資料

## 対象製品

- 製品: ヴイストン オムニローバー3WD
- 搭載オムニホイール: Nexus Robot 14108
- 搭載サーボモーター: Nexus Robot 16007（RB-Nex-40）

搭載部品は、ヴイストン公式の「全方位移動台車」作例データに含まれる部品表で確認した。

## ディレクトリー構成

- `system/`: オムニローバー3WD本体の取扱説明書と、ヴイストン公式作例データ
- `omniwheel_14108/`: 48 mmオムニホイールの仕様書とメーカー公開3Dモデル
- `servo_16007/`: 無限回転メタルギアサーボの仕様書

## オムニホイール 14108

主な仕様は、直径48 mm、幅25.1 mm、軸穴径12 mm、質量約39 g、負荷上限2 kg、ローラー8個である。3Dモデルはメーカー公開のSTPデータである。

## サーボモーター 16007

主な仕様は、外形19.7 mm × 41.7 mm × 42.9 mm、質量約55 g、トルク13 kgf・cm、回転速度53～62 rpm、電源電圧3～7.2 V、動作電流100 mAである。

同一型番 `16007 / RB-Nex-40` の公開3Dモデルは、2026年8月29日の調査時点でメーカー、ヴイストン、RobotShopの公開ページから確認できなかった。寸法が近い汎用サーボのCADデータは、取り付け穴や出力軸位置の一致を保証できないため収録していない。
