# FR-03 位置制御指令

## 内容

目標位置（ワールド座標 x, y）と走行速度を入力し、ロボットを位置制御で移動させる。

## 仕様

- 目標 x, y [m] と速度上限 [m/s] を数値入力し、`SET_POSE_TARGET` リクエストで送信する。送信は明示的なボタン操作で行う。
- 送信中の目標と現在位置を同一の俯瞰マップ上にプロットし、目標への残距離を表示する。
- 新しい `SET_POSE_TARGET` の送信は現在の目標を上書きする。`STOP` リクエストで位置制御動作を中断できる。
- 位置制御モードへの移行はロボット側の受理（ACK 結果コード）で確認し、拒否時は理由を表示する。
- 速度上限はロボットの `max_speed` を超える値を入力できないよう UI でクランプする。

## 根拠

運用パターン「定点移動」の要求。ロボット側の位置制御本体は `ball_balancing_omni3_stm32` FR-10 が担当し、本アプリは指令送信と状況提示を担当する。
