# FR-07 運転開始・停止と開始前準備

## 内容

アプリから動作開始・停止コマンドを送り、開始前の IMU キャリブレーションと所定位置へのセッティングを操作できるようにする。

## 仕様

- ロボットの動作状態（待機／動作中／終端）を `STATUS`/`EVT_STATUS` の `op_state` で表示し、全画面共通の app-shell に状態バッジを常設する。
- ホーム画面に開始前準備パネルを設け、以下を操作可能にする:
  - `CALIBRATE_IMU` の送出と、実施中の進行表示・`CALIB_RESULT` の結果表示。
  - `SET_POSE` による現在位置・姿勢の所定値設定、および `RESET_ODOMETRY` による原点リセット。
  - `START_OPERATION` / `STOP_OPERATION` の送出。
- 開始ボタンは未接続・キャリブレーション未完了・ロボット側拒否条件の存在時にガイドを表示し、実行可否を `STATUS` の状態から操作者へ明示する。
- 動作中でない間は速度指令・位置目標の送信 UI を無効化する（FR-02, FR-03 のガード）。
- 全画面共通の緊急停止ボタン（FR-06）は `STOP`（運動指令ゼロ＋その場保持）を維持し、モータ駆動を遮断して待機へ戻る `STOP_OPERATION` とは区別して操作者が選択できるようにする。

## 根拠

`ball_balancing_omni3_stm32` FR-12（動作状態管理）、FR-13（キャリブレーション・初期位置設定）。起動前の配置・キャリブレーションをアプリ操作で完結させるため。
