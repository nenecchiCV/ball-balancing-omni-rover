# FR-08 テストコマンド送受信

## 内容

STM32 テストアプリ（`tests/onboard` の `link_test`）および本番ファームとのプロトコル疎通を検証するため、テスト用コマンドの送受信機能を提供する。

## 仕様

- テストページ（`/test`）から `PING`・`GET_STATUS`・`TEST_ECHO` を送信し、応答内容と往復時間を表示する。
- `TEST_ECHO` は任意長ペイロード（hex または ASCII 入力、プロトコルのペイロード上限まで）を送り、`TEST_ECHO_RESP` のペイロード一致を表示する。
- `PONG` の `robot_caps` をビット内容で表示し、接続先がテストビルド（bit3）か本番ファームかを識別できるようにする。
- 本機能は接続中であれば動作状態に依らず利用できる。

## 根拠

テストファーム（`ball_balancing_omni3_stm32` spec/test/link_test）とのリンク・プロトコル疎通を、本番機能の実装完了を待たずに検証するため。
