# FR-01 BLE 接続管理

## 内容

BLE セントラルとしてロボット（無線変換器）を検出・接続・切断し、接続状態を UI へ提示する。

## 仕様

- 周辺機器スキャンを実行し、デバイス名 `uwc-esp32c6` を既定フィルタとして一覧に提示する。名称一致以外のデバイスも手動選択で接続対象にできる。
- 接続後は NUS 相当サービスを検出し、RX 特性（Write）と TX 特性（Notify）を確保してから通知購読を開始する。
- 接続状態（切断中 / スキャン中 / 接続中 / 接続済）を全画面共通のインジケータで常時表示する。
- 切断時は再接続ボタンで同一デバイスへ再接続できる。異常切断はログ表示に記録する。
- 接続確立時に `PING` リクエストでプロトコルバージョンを照合し、不一致時は警告を表示する。

## 根拠

`uart_wireless_converter_esp32` FR-01/FR-02（NUS 透過、自動再 advertising）。
