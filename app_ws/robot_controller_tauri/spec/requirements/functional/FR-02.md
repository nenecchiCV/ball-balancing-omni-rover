# FR-02 ラジコン操作（速度指令）

## 内容

画面上の 2 本のバーチャルジョイスティックでロボットへ速度指令を送る。

## 仕様

- 左スティックは並進速度（上下 = 前後 vx、左右 = 横移動 vy）、右スティックは回転速度（左右 = ヨーレート）を指定する。指令座標系はロボットのワールド座標系に対する `SET_VELOCITY` の意味に従う。
- スティック操作量は -1.0〜+1.0 に正規化し、最大速度 0.4 m/s・最大ヨーレート 0.8 rad/s（`control_params.controller.max_speed` / `max_yaw_rate`）へスケーリングする。
- 操作中は 50 ms 周期（20 Hz）で最新指令を送り続ける。スティック解放時はゼロ指令を 1 回送出する。
- 指令送信は速度指令モードでのみ有効とし、画面表示は現在の制御モードを反映する。
- デッドマン扱い: ロボット側の指令ウォッチドッグ（500 ms 無指令で停止、プロトコル仕様参照）を前提に、アプリ側でも送信停止時の状態を操作者へ明示する。

## 根拠

`ball_balancing_omni3_stm32` FR-07（移動指令生成）と速度リミット定数。
