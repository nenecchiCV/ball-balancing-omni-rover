# FR-05 ログ表示

## 内容

ロボットが送出するログメッセージを受信し、時系列リストで表示する。

## 仕様

- `EVT_LOG` ストリームを購読し、レベル（DEBUG/INFO/WARN/ERROR）・時刻・本文を表示する。
- レベルフィルタと一時停止・クリア操作を提供する。表示中の過去ログは保持する。
- アプリ自身のイベント（接続・切断・送信失敗・ACK 拒否）も同一リストに `APP` ソース識別子付きで記録する。
- ログ件数はメモリ保護のため上限（既定 5000 件）を設け、超過分は古い順に破棄する。

## 根拠

`ball_balancing_omni3_stm32` FR-08（診断出力）の無線リンク経由版。ST-Link VCP が使えない無線運用時の主要な観測手段。
