# NFR-02 安全設計

## 内容

誤操作・誤指令による危険動作を防ぐ。

## 仕様

- 速度指令・位置指令の送信値は UI 入力段階と送信直前の 2 段階でレンジクランプする（`max_speed` 0.4 m/s、`max_yaw_rate` 0.8 rad/s）。
- 位置制御・リセット系の操作（`SET_POSE_TARGET`、`RESET_ODOMETRY`）は明示的ボタン操作を必要とし、スティックのような連続入力と区別する。
- 緊急停止ボタンは全画面で同一配置・同一見た目とし、確認ダイアログなしで即時送信する。
- 未接続状態では指令系ボタンを無効化し、送信不能な操作を UI 上成立させない。
- プロトコルの CRC 不一致・未知タイプの受信フレームは破棄し、指令系値として採用しない。

## 測定方法

クランプ境界値・未接続時の無効化はホスト側のコードレビューと手動確認で検証する。
