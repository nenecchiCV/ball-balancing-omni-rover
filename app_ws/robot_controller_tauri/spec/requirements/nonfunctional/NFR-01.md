# NFR-01 応答性・実時間性

## 内容

操作指令の遅延とテレメトリ表示の実時間性を、遠隔運転用途として十分な水準に保つ。

## 仕様

- スティック操作から `SET_VELOCITY` 送信までのアプリ内遅延は 50 ms 以内（20 Hz 送信周期）とする。
- `EVT_POSE` の既定購読レートは 20 Hz とし、UI 描画は受信遅延を目視で追える水準（描画更新 20 Hz 以上）とする。
- リクエストの応答タイムアウトは 1 s（FR-06）。タイムアウトはリトライせず失敗として返す。
- ログ表示・オドメトリ描画は受信スレッドをブロックしない。受信処理と UI 更新はイベント経由で分離する。

## 測定方法

BLE 接続間隔（7.5–30 ms、`uart_wireless_converter_esp32` NFR-01）に対し、`PING` 往復時間と `EVT_POSE` の受信間隔をログタイムスタンプで確認する。目標値は実機で見直す。
