# FR-02 リンクライフサイクル管理

## 内容

無線リンクの接続状態遷移を管理し、接続・切断を自律的に処理する。

## 仕様

- 起動後ただちに connectable advertising を開始し、セントラルからの接続を待つ。
- 切断検出時は自動的に advertising を再開し、再接続を待つ。
- 接続状態（advertising / connected / disconnected）は `link_monitor` が遷移イベントとして記録し、診断 shell から参照できる。
- UART 受信・送信の活動時刻を保持し、診断用に最終活動時刻を照会できる。無線リンクの断絶は本モジュールではアラーム化のみとし、ホスト側への通知方法（UART 無応答のタイムアウト等）はホスト側アプリ層の責務とする。

## 根拠

ロボット搭載時にユーザーの手を介さずリンクを維持するため。断絶時の安全停止判定は制御系を持つホスト側（G474）の責務とする分業。
