# FR-05 リンク状態 LED 表示

## 内容

無線リンクの状態を基板上のユーザー LED で外部から視認できるようにする。

## 仕様

- XIAO ESP32-C6 基板上のユーザー LED（GPIO15、ボード dts の `led0` / `yellow_led`、アクティブ Low）をリンク状態の表示に使用する。
- リンク状態が `WAITING`（advertising / 接続待受中）の間、1 秒周期で点滅する（0.5 s 点灯 / 0.5 s 消灯）。
- リンク状態が `CONNECTED` の間、常時点灯する。
- リンク状態が `IDLE`（初期化前・advertising 停止中）の間、消灯する。
- 切断時は FR-02 に従い自動的に advertising を再開して `WAITING` へ戻り、LED も点滅表示へ戻る。
- LED 表示は `link` の状態遷移（`link::state` / `link::event`）に追従し、無線トランスポート種別（BLE / Wi-Fi）に依存しない。
- LED 制御はバイトストリームの転送処理をブロックしない。

## 根拠

ロボット搭載後に診断シェルを開かず接続状態を確認するため。advertising 中（接続待ち）と接続中を点滅/点灯で区別し、未接続のまま取り残された状態を現場で即座に検出できるようにする。
