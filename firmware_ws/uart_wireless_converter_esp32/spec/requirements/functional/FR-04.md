# FR-04 トランスポート切替可能構成

## 内容

無線トランスポート実装を BLE と Wi-Fi（将来）で切替可能とし、UART 側インターフェース・ブリッジ機構は切替に無関係とする。

## 仕様

- トランスポートは `device/link` の `link` static class として統一静的インターフェース（`init`/`connected`/`max_payload`/`send`）を持ち、実装ファイルをビルド時に選択する（`link_ble.cpp` / `link_wifi.cpp`）。
- 選択は Kconfig `UWC_TRANSPORT_BLE` / `UWC_TRANSPORT_WIFI` で行い、CMake が対応するソースのみをコンパイルする。アプリケーションコード内の `#ifdef` による切替は使わない。
- `uart_bridge` 以降の層はトランスポート種別を知らない。Wi-Fi 実装の追加は `link_wifi.cpp` の新設と Kconfig 選択のみで完結させる。
- Wi-Fi 実装は SoftAP + 固定 IP + TCP（または UDP）を想定する。詳細は実装時に要求へ追加する。

## 根拠

ハードウェア（XIAO ESP32-C6、基板実装アンテナ）を変えずに無線方式を後から見直せるようにするため。応答性・消費電力・ホスト側 UI の実測比較に基づき最終選択する。
