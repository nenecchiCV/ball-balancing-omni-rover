# FR-03 診断 shell

## 内容

USB-Serial-JTAG（`usb_serial`）上の Zephyr shell からリンク状態・転送統計を照会できる。

## 仕様

- shell は `usb_serial` ノード（USB-Serial-JTAG）に出す。ホスト UART（UART0）はデータリンク専用とし、console/shell を共有しない。
- `uwc status` — トランスポート種別、接続状態、（BLE 時）接続先アドレス・MTU・PHY、最終活動時刻を表示する。
- `uwc stats` — 方向別の転送バイト数・送出失敗数・破棄バイト数を表示し、`uwc stats reset` でクリアする。
- リンク未接続でも shell は動作し続ける。

## 根拠

現場での疎通確認と断絶解析のため。診断経路とデータ経路を分離し、透過ストリームを診断文字列で汚染しない。
