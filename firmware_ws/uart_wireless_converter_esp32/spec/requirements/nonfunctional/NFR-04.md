# NFR-04 メモリ管理

## 内容

アプリケーション側はヒープを使わない。ESP32 無線スタック（hal_espressif blob）が内部で必要とする確保のみをカーネルヒープで許容する。

## 仕様

- `CONFIG_HEAP_MEM_POOL_SIZE` は 0 にしない（`ball_balancing_omni3_stm32` と異なる点）。ESP32-C6 の BLE/Wi-Fi コントローラと Zephyr BT ホスト内部が `k_malloc` 系に依存するため。初期値は 32768 とし、実機での安定稼働後に削減を検討する。
- アプリケーション側コードは `new`/`delete`/`malloc` を使わず、全バッファを静的/スタック確保する。
- UART↔無線の中継バッファは固定長 `struct ring_buf`（静的確保）とする。容量は UART ボーレートと BLE 送出周期から設計し、オーバーフローは破棄として統計に記録する。

## 測定方法

コードレビュー（`new`/`malloc` 不使用）と、長時間転送試験でのリングバッファ残留・統計カウンタ確認。
