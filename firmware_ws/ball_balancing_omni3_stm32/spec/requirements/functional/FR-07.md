# FR-07 移動指令生成

## 内容

運転指令（ワールド速度・ヨーレート）を生成し、制約付きで制御器へ渡す。

## 仕様

- 指令は `command = [vx_W; vy_W; yawRate]` の 3 要素。
- 既定はサイクルプロファイル: 走行区間 → 停止区間 → 必要に応じてヨーパルスを繰り返す。加速度/減速度リミットは台形プロファイルで適用する。
- 指令は制御器内部で連成（速度・ヨーレート）リミット、`maxSpeed`・`maxYawRate` キャップ、フォロースルーブレーキを経て適用される。
- 指令の実体は UART 受信または内部プロファイルとして、コンパイル時切替ではなく実行時に選択可能な構造とする（初期実装は内部プロファイル固定 + UART 上書き受付）。

## 根拠

`ballbotParameters.m` の `command` 構造と `ballbotLqiControllerUpdateRev2.m` の指令前処理。
