# FR-06 非常停止

## 内容

非常停止入力（外部 E-Stop + 基板ボタン）を検出したら直ちに全モータ出力を遮断する。

## 仕様

- PC0（外部スイッチ、アクティブロー）または PC13（基板ボタン）のいずれかが停止要求を示したらイネーブルを落とす。
- 停止要求は次の外側タスク周期（5 ms）以内に mode 0 へ反映し、内側タスクのデューティを 0 にする。
- 停止後は電源再投入まで復帰しない（mode0 ラッチと同一の終端仕様）。

## 根拠

`hardware_config.md` の安全要件。制御ソフトが mode 0 を終端として扱う構造と整合させる。
