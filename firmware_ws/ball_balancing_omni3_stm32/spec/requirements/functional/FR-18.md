# FR-18 センサ生データ送出

## 内容

IMU（加速度・角速度）とホイールエンコーダの生データを、購読型プロトコルイベントとしてアプリへ送出する。

## 仕様

- `SUBSCRIBE(EVT_SENSORS, rate_hz)` 受理後、`EVT_SENSORS`（`t_ms, accel f32[3], gyro f32[3], enc_count i32[3]`、40 B）を指定レート（1–50 Hz）で送出する。`UNSUBSCRIBE` またはリンク断絶で停止する。
- `accel`/`gyro` は `imu_sample`（`lsm6dso::read()` の機体軸写像後・推定処理前の値）をそのまま載せる。
- `enc_count` は各車輪 `encoder_counter::count()` の累積生カウントを `i32` へ切詰めて載せる（ラップは自然許容）。
- 生成は外側タスク（200 Hz）で行い、`EVT_POSE` と同じレート分周・FR-14 のイベントバッチ規則に従う。同一窓内は最新値のみ保持する。
- 待機・動作中・故障のいずれの動作状態でも送出でき、送出処理は制御スレッドの実時間性を阻害しない。

## 根拠

`app_ws/robot_controller_tauri` FR-11（センサ生データ表示）。配線・軸写像・エンコーダ極性の実機確認をリンク経由で行うため。
