# FR-16 駆動不感帯補償

## 内容

モータ・ドライバ系の静止摩擦不感帯を補償し、微少トルク指令での応答性と
倒立保持時の微振動を改善する。テストアプリ `omni_drive_test` の
`DEADZONE_COMP` 相当を本番 `wheel_servo` に導入し、車輪ごとに調整可能な
パラメータとする。

## 仕様

- `param_set` に `drive.deadzone_comp_pos[3]`・`drive.deadzone_comp_neg[3]`
  （車輪ごと・回転方向ごとの補償デューティ、既定 0.08、
  `omni_drive_test` と同値）を追加する。
- `wheel_servo::step` の出力段で、非ゼロの出力デューティへ
  `duty += copysignf(comp, duty)` を適用する。`comp` は duty 符号が
  正なら `deadzone_comp_pos[i]`、負なら `deadzone_comp_neg[i]` を選ぶ。
  `|duty|` が上限を超える場合は出力飽和クランプが先に適用される構成を
  維持し、補償後の値が物理上限を超えないようクランプする。
- 出力がゼロのとき（指令ゼロ・待機中）は補償を加えず、出力はゼロのまま
  とする。
- 正転用は `SET_PARAM`（key `0x00-0x02`）、逆転用は
  `SET_PARAM`（key `0x03-0x05`）で動作値を即時変更でき、
  `SAVE_PARAMS` で永続化される。
- 補償値の同定は FR-17 の `TUNE_DEADZONE` 掃引で行い、`TUNE_RESULT` の
  `recommended` を反映する。掃引方向（`dir`）に対応する側の
  `deadzone_comp_pos/neg` へ適用する。

## 根拠

ブラシ付き DC モータ + ギヤヘッド系では静止摩擦により小デューティが
出力されない。倒立保持では微小な位置ずれに対して小さい補正トルクを
要求するため、不感帯未補償だと微振動・定常ずれが残る。車輪ごとの差を
吸収するため個別パラメータとする。
