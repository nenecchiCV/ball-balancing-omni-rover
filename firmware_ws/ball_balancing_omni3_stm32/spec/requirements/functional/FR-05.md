# FR-05 制御モード管理

## 内容

制御モード（0: 終端 / 1: 通常 / 2: 回復）の遷移、エレベーテッド権限（settle）管理、ヨーバイアス準備フラグを管理する。

## 仕様

- イネーブル喪失・`fallenTilt`（0.61 rad）超過・mode0 ラッチで mode 0（終端）に遷移する。mode 0 は再び mode 1/2 に戻らない。
- `recoveryTilt`（5°）超過で mode 2、mode 2 中は `recoveryExitTilt`（2°）未満で mode 1 へ戻るヒステリシスを持つ。
- mode 2 への移行でエレベーテッド権限をアームし、mode 1 復帰後もフィルタ輪速が `recoveryAuthorityClearRate`（1.5 rad/s）未満に落ちるまで維持する。この間は settle 処理（エンコーダ由来速度への切替、推進遮断）を行う。
- ヨーバイアス準備フラグは静止資格 + ヨーレートしきい値で一度立てばラッチする。

## 根拠

`ballbotLqiControllerUpdateRev2.m` のモード/エレベーテッド権限ロジック、`ballbotYawBiasStartupGuard.m`。
