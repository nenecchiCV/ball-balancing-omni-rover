# FR-13 IMU キャリブレーション・初期位置設定

## 内容

動作開始前のセットアップとして、リンク経由で IMU（ジャイロバイアス・姿勢オフセット）キャリブレーションの実行と、現在位置・姿勢の所定値への設定を可能にする。

## 仕様

- `CALIBRATE_IMU` は `standby` 中のみ受理し、受理時にジャイロバイアス学習状態（`gyro_bias_z`・EKF バイアス・`qualification_time`）をリセットする。以後、推定器の静止資格が `bias_qualification_time`（0.5 s）連続成立で完了とし、`CALIB_RESULT`（result=0）を即時送出する。`calib_timeout_ms`（既定 5 s）内に成立しない場合は result=1（静止未検出・タイムアウト）、IMU 異常時は result=2 で送出する。
- 完了時（result=0）に、静止中の生比力から姿勢オフセット（roll/pitch の傾斜成分）を捕捉して `imu.att_offset_roll`/`imu.att_offset_pitch` を更新する。捕捉は機体が略正立（比力の +z 成分が正）のときのみ行い、不成立時は従来値を維持する。捕捉値は `CALIB_RESULT` の `att_offset_*` フィールドで報告し、`SAVE_PARAMS` で永続化される（FR-15）。
- 姿勢オフセットは推定器への IMU 入力（比力・ジャイロ）と車輪ジオメトリへ同一回転として適用し、捕捉時の姿勢が推定傾斜 0 となるようにする（機体を傾き 0 とみなす基準姿勢 = 運用床上のセットアップ姿勢）。yaw は補正対象外とし、ワールド座標の水平面は重力基準のままとする。
- キャリブレーションの状態は `STATUS`/`EVT_STATUS` の `calib_state`（0=未実施、1=実施中、2=完了、3=失敗）で報告する。再実行は `standby` 中いつでも可能とする。
- `SET_POSE` は `standby` 中のみ受理し、現在のオドメトリ姿勢・位置を指定の `(x, y, yaw)` へ設定する（所定位置へのセッティングに相当）。受理時に位置目標を解除する。
- `RESET_ODOMETRY` は従来どおり随時受理とする（`SET_POSE(0,0,0)` 相当）が、受理時に位置目標を解除するよう仕様を強化する。

## 根拠

運用要求（動作開始前の IMU キャリブレーションと所定位置セッティング）。既存のバイアス qualification は連続動作するのみで、アプリから明示的に実行・確認する経路がなかった。姿勢オフセットは、IMU 取付ずれに加えて実際の運用床（完全な水平とは限らない）を基準面にしたい要求に対応するもので、「床の上で静置した姿勢を傾き 0 とする」較正として `CALIBRATE_IMU` に統合する。
