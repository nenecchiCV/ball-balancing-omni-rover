# FR-01 状態推定

## 内容

200 Hz で IMU（比力・角速度）と輪速から、ロール/ピッチ/ヨー、体軸角速度、ワールド系水平速度、ボール角速度、ローバ–ボール相対位置を推定する。

## 仕様

- 状態ベクトルは 14 要素（quaternion4 + ワールド速度3 + ボール角速度3 + 相対位置2 + ヨーバイアス1 + 資格化時間1）を保持する。
- 5 状態誤差 EKF（姿勢誤差3 + roll/pitch ジャイロバイアス2、Joseph 形更新、姿勢共分散フロア付き）を既定で有効とする。
- ヨー軸ジャイロバイアスは資格化静止検出（車輪静止・加速度規格・角速度しきい値・ヒステリシス付き）で別途学習する。
- ボール角速度は車輪接触の運動学求解（正則化付き最小二乗）で求め、静止保持時間（1 s）ゲートとローパスを経て採用する。
- 速度は加速度積分に対し、アンカー（ボール速度への引き寄せ）と静止ドレインでバイアスを除去する。

## 根拠

`ballbotEstimatorStep.m` の挙動を `float` に移植する。
