# FR-02 輪速計測

## 内容

3 系統の正交エンコーダ変位から各車輪の角速度 [rad/s] を算出する。

## 仕様

- 計測窓は 5 ms（外側タスク周期）とする。1 ms で後退差分すると量子化フリッカ ~18.5 rad/s がデューティ経路を不安定化するため、1 kHz タスクは 5 ms 窓の保持値を使う。
- 変位 = エンコーダカウント差 × `2π / countsPerRev`。`countsPerRev` は x4 デコードを含む換算定数で、実機測定により確定する。
- 内側サーボ用の逆起電力補償には 25 ms 時定数のローパスを別途掛ける（`ballbotWheelServoDutyStep` 相当）。

## 根拠

`ballbotWheelRateFromDisplacement.m` と `hardware_config.md` のタイミング要件。
