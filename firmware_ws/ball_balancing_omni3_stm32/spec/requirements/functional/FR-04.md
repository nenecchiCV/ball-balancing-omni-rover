# FR-04 車輪サーボ（内側タスク）

## 内容

1 kHz で外側タスク出力の姿勢トルク・輪速コマンドに推進サーボを合成し、DC モータ方程式で PWM デューティへ反転する。

## 仕様

- 逆起電力補償用輪速は 25 ms 時定数のローパスを掛ける。
- 推進サーボ: 輪速誤差 → デッドゾーン → P ゲイン → トルク上限・姿勢トルクとのヘッドルーム配分・最小シェア保証。settle 中は推進を遮断する。
- 合成トルク → 電流 → `duty = (R・i + Ke・ω) / Vsupply` でデューティを算出し、`maxDutyCycle` にクランプする。
- `R` は電機子抵抗 + ブリッジオン抵抗（2.225 Ω）を用いる。
- 内側レートのソフトスタートランプ（`startupTorqueRampTime` 0.4 s）を推進チャネルに適用する。

## 根拠

`ballbotWheelServoDutyStep.m` の挙動を `float` に移植する。
