# FR-15 パラメータ不揮発保存

## 内容

制御器ゲイン・駆動不感帯・IMU 特性を含む動作パラメータをメインフラッシュの
`storage_partition`（0x7F000 起点 4 KB）へ保存し、電源再投入後も調整結果を
維持できるようにする。

## 仕様

- `param_set` はコンパイル時既定値を持つ constexpr 構造体とし、起動時に
  「既定値 → RAM 上の動作値 `param_store` へ展開 → フラッシュ保存値で
  上書き」の順に初期化する。フラッシュ未書込・破損・スキーマ不一致時は
  既定値で起動する。
- 保存フォーマットは `{magic, schema_ver, seq, param_set, CRC32}` とし、
  `storage_partition` 内で 2 スロット交互書きとする。起動時は CRC 妥当な
  最新スロットを採用する（書込み途中の電源断で片側が壊れても前回値で
  起動できる）。
- `SAVE_PARAMS` は `op_state == STANDBY` のときのみ受理し、フラッシュの
  消去・書込み完了を確認してから `result=0` を返す。消去・書込みは
  ms オーダのストールを伴うためリンクスレッドで同期実行する。
- `RESET_PARAMS` は `op_state == STANDBY` のときのみ受理し、動作値を
  既定値へ戻すとともに両スロットを消去する。
- `schema_ver` は `param_set` のレイアウト変更時にインクリメントし、
  不一致の保存値は無効として既定値で起動する。
- 起動時に `imu` セクションの保存値（`gyro_bias_z`・`ekf_bias_xy`）を
  `state_estimator` のバイアス状態へ適用する。`CALIBRATE_IMU` による
  再学習結果は `SAVE_PARAMS` で永続化される。

## 根拠

EEPROM 相当の不揮発記憶を別チップなしに実現するには、メインフラッシュ
末尾の予約領域を使うのが最小構成である。調整のたびに再ビルド・再書込み
する運用を避け、現場でのゲイン・不感帯・IMU 特性の個体調整を可能にする。
制御中のフラッシュ消去（ms 級ストール）は実時間性を損なうため、保存は
待機中に限定する。
