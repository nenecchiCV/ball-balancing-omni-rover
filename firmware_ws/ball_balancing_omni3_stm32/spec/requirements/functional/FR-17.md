# FR-17 調整・同定インターフェース

## 内容

調整対象パラメータの一覧取得・個別設定・不感帯の自動掃引同定をリンク
経由で行えるようにし、アプリからの手動調整および半自動同定を可能にする。

## 仕様

- `GET_PARAMS`（`start_key` 指定）は調整対象パラメータを key 昇順で
  `PARAMS`（`{seq, total, count, [key, value]*}`）として返す。1 フレームに
  収まる件数のみ返し、`total` は調整対象 key の全件数を示す。受信側は
  末尾 key + 1 を `start_key` に指定して `total` 件集まるまで繰り返す。
  調整対象 key はプロトコル正本「調整対象パラメータ」表に従う。
- `SET_PARAM`（`key, value`）は動作値へ即時反映する。未定義 key および
  範囲外値は `INVALID_PARAM` で拒否する。
- `TUNE_DEADZONE`（`dir, max_duty, ramp_s`）は `op_state == STANDBY` の
  ときのみ受理し、`op_state` を `3`（調整中）へ遷移させて三角掃引を
  実行する。掃引中は平衡制御を行わず、`0 → dir*max_duty → 0` の
  デューティを全車輪へ同時印加し、5 ms 窓の輪速で各車輪の
  「上り掃引立上りデューティ（|w| が閾値超となる最小 |duty|）」と
  「下り掃引維持限界」を同定する。
- 完了・中断時に `TUNE_RESULT`（`{seq, result, dz_start[3], dz_keep[3],
  recommended[3]}`）を即時送出し、`op_state` を `STANDBY` へ戻す。
  `recommended` は車輪ごとの `立上り/維持限界の中間値`とする。
- 掃引中の E-Stop はデューティを即時ゼロ化して掃引を中断し、
  `TUNE_RESULT`（`result=1`）で報告する。`STOP_OPERATION` でも掃引を
  中断する。掃引中は `START_OPERATION` を `REJECTED_STATE` で拒否する。
- 実施前提（車体を人が保持し 3 輪すべてを無負荷とすること）はアプリ側
  画面のガイド表示で明示する。ファーム側は車輪未回転時に
  `result=2` で失敗を報告する。

## 根拠

不感帯は個体差・経時変化があり、テストアプリのみの同定では本番
ソフトへ反映できない。本番ソフトに調整系コマンドと掃引セッションを
持たせることで、アプリからの一連の調整フロー（取得→掃引→適用→保存）
を完結できる。
