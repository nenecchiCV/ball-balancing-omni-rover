# FR-09 ロボットリンクプロトコル受付

## 内容

USART1（115200 8N1、PC4=TX / PC5=RX、無線変換器 `uart_wireless_converter_esp32` 経由の BLE リンク）でロボットリンクプロトコルのフレームを受信・解釈し、指令適用と応答送出を行う。

## 仕様

- プロトコルは `app_ws/robot_controller_tauri/spec/basic_design/robot_link_protocol.md` を正本とする（フレーム形式: SYNC `0xA5` + TYPE + SEQ + LEN + PAYLOAD + CRC16）。
- 受付対象: `PING`、`SET_VELOCITY`、`SET_POSE_TARGET`、`STOP`、`SET_CONTROL_MODE`、`RESET_ODOMETRY`、`SUBSCRIBE`/`UNSUBSCRIBE`、`GET_STATUS`。
- 応答は `ACK`（result コード付き）、`PONG`、`STATUS` を仕様のペイロードで返す。`PONG` の `robot_caps` は実装済み機能に対応させる。
- `SET_VELOCITY` は FR-07 の UART 上書き経路として適用し、内部プロファイルより優先する。受信指令は制御器側の連成リミット・キャップを通過する既存経路をそのまま使う。
- 安全側処理: 最終 `SET_VELOCITY` 受信から 500 ms 無指令で指令をゼロとするウォッチドッグを持つ。UART アイドル 1 s 超過（リンク断絶）でもゼロとする。
- 受信は制御スレッドの実時間性を阻害しない（割込/リングバッファ受領 + 制御周期内の短時間処理に限定する）。

## 根拠

`app_ws/robot_controller_tauri` FR-01〜FR-06。`uart_wireless_converter_esp32` の hardware_config（USART1 接続・生バイト透過）。
