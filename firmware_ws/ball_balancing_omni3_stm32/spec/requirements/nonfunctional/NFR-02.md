# NFR-02 静的メモリ管理・計算量

## 内容

動的メモリ確保を使わず、全バッファは静的確保とし、各タスクの最悪実行時間を周期未満に抑える。

## 仕様

- `new`/`delete`/`malloc`/`free`、STL の動的コンテナ、例外、RTTI は使わない。
- 行列・ベクトルは `std::array` ベースの固定サイズ型とする。
- 計算量見積り: 外側タスク（EKF 5x5 + LQI 3x10 + 運動学求解 3x3）は 5 ms 未満、内側タスク（数 ops + duty 反転）は 0.1 ms 未満を目標とする。
- スタック使用量はリンカ統計または実行時計測で確認し、メインスタック 8 KB 以内に収める。

## 測定方法

ビルド時の map ファイル、DWT 計測、stack-usage 解析で確認する。
