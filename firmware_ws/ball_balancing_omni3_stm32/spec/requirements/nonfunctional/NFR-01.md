# NFR-01 制御周期の厳守

## 内容

外側タスクは 5.0 ms 周期、内側タスクは 1.0 ms 周期で実行し、ジッタは外側 ±0.2 ms・内側 ±0.05 ms 以内とする。

## 仕様

- 内側タスクは TIM6 の 1 kHz 割込で起動し、外側タスクは同じタイムベースの 5 カウント目に起動する。
- 外側タスクは内側タスクの前に完了する必要はなく、内側は ZOH した外側出力を使う。
- 実時間保証は割込優先度設計（制御タスク > UART・診断）と実行時間上限で達成する。

## 測定方法

デバッグ端子トグルまたは DWT サイクルカウンタで起動間隔・実行時間を計測する。
